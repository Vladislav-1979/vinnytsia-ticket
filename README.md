# Вінниця 24 — оновлена demo-PWA

## Що змінено

- «Ще сервіси» тепер інтерактивне: натискання відкриває екран «Оплата».
- Екран «Оплата» стилізований під наданий еталонний скриншот: темна тема, `Міський транспорт`, −25.00 UAH, статус, картка, прихований залишок, категорія та «Допомога Онлайн».
- Над заголовком «Міський транспорт» використовується `machine.png`.
- Кнопка `×` на «Оплата» повертає на «Архів».
- Дата/час «Оплата» фіксуються на момент завантаження поточної сесії та не перегенеровуються при переходах між екранами.
- Генерація архівних блоків 3/4 з учорашньою датою та випадковим часом 07:00–21:59 збережена.
- «Залишок» на «Оплата» показується крапками: `· · · · · · · UAH`.
- QR квитка тепер містить URL з серією, вагоном і timestamp сесії. На іншому смартфоні такий QR може відкрити екран «Результат» із тими самими даними.
- Таймер «Результат» рахує залишок до 00:00 за часовим поясом `Europe/Kyiv`, використовуючи timestamp, записаний у QR.
- Для «Результат» додано `result-logo.png`, обрізаний із наданого скриншота.
- Service Worker оновлено до v5 і додано нові локальні зображення в кеш.

## Публікація на GitHub Pages

1. Розпакуйте ZIP.
2. У репозиторії замініть старі файли файлами з папки `vinnytsia-ticket-main`.
3. Зробіть Commit changes.
4. Зачекайте 1–2 хвилини, поки GitHub Pages опублікує нову версію.
5. Відкрийте застосунок і, якщо бачите стару версію, повністю закрийте встановлений PWA та відкрийте сайт ще раз.

## Перевірка QR на двох телефонах

1. На першому телефоні відкрийте «Архів».
2. Серія та вагон першого квитка використовуються для QR.
3. Згенеруйте/покажіть QR.
4. На другому телефоні відскануйте його штатною камерою.
5. Посилання відкриє цей же GitHub Pages сайт у режимі `Результат`, із серією, вагоном і часом тієї сесії.

> Важливо: це статичний GitHub Pages demo. Серверної бази даних немає, тому синхронізація між телефонами здійснюється через дані, закодовані безпосередньо в QR URL.
