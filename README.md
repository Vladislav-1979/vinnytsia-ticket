# Вінниця 24 — PWA додаток квитків

## Встановлення як додаток на смартфон

1. Завантажте всі файли на **GitHub Pages** (або будь-який HTTPS-хостинг):
   - index.html
   - manifest.json
   - sw.js
   - icon-*.png

2. Відкрийте сайт у **Chrome / Safari** на телефоні.

3. **Android (Chrome):** меню → «Додати на головний екран» / «Встановити додаток».

4. **iPhone (Safari):** Поділитися → «На екран „Додому“».

Після встановлення додаток відкривається в повноекранному режимі без адресного рядка, з іконкою «Вінниця 24».

## Функції

- Таймер зворотного відліку запускається автоматично при кожному відкритті
- Сканер QR через камеру
- Екран «Про компанію» з інформацією
- Офлайн-кешування через Service Worker
- Іконка з логотипом «24»
